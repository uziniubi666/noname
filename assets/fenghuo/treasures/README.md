# 烽火宝物图片资源

这些图片从 `D:\sanguosha` 的宝物/消耗品详情头部直接无损裁剪，保留原始背景与品质边框。图片不含详情文字；没有生成重绘、抠透明背景或放大。当前来源图片是截图，因此原始清晰度受截图限制。

| 子目录 | 来源截图组 | 游戏类型 |
| --- | --- | --- |
| `active/` | 主动宝物 | active |
| `passive/` | 被动宝物 | passive |
| `rare-passive/` | 稀有被动宝物 | passive，实际也包含普通品质 |
| `consumables/` | 消耗品 | consumable |

使用 [preview.html](preview.html) 查找名称、品质与来源类别；使用 [manifest.json](manifest.json) 获取图片相对路径、实际品质、套装归属（如有）、原图尺寸、SHA-256 和裁剪坐标。

文件名为 `名称--品质--原图哈希前8位.png`。每张宝物截图各导出一张，因此相同宝物可能有多份来源图。`preferred: true` 标记同一类型、名称和品质中尺寸较大的推荐图片。正式 UI 可先筛选 `preferred`，再用名称、类型、品质建立映射；正式宝物效果 ID 尚未定义。

`manifest.json` 中 `category` 表示来源截图组，`type` 表示游戏类型，`quality` 表示截图中实际品质。图片 `id` 用于资产溯源，不作为正式玩法配置 ID。

`contact-sheet-*.jpg` 是便于检查的图片联系表。它们可能缩放图标，正式 UI 应读取分类子目录中的 PNG。各 PNG 保持原图尺寸，建议在 UI 中使用 `object-fit: contain`；放大无法补回原截图缺失的细节。

重新生成需要原始截图、结构化记录与导出脚本；这些源文件不包含在本资源目录内。本目录仅提供图片资源，尚未改动现有 UI 或扩展构建。
